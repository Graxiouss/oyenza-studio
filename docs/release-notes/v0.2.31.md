# Oyenza Studio 0.2.31

**Lyrics and volume, together.** The Music page has a Lyrics switch, a system-volume slider and mute. Turn Lyrics off and the closed island keeps its usual size, with an animated waveform while music plays.

The waveform uses the existing redraw loop only while media is playing. It rests when playback stops, Battery Saver is on, the session is locked or the display is off. No new background thread or polling.

**Windows:** download `Oyenza-Studio-Setup.exe` and run it, or unzip the portable zip and run `Poni\poni.exe`. It installs just for you, without admin rights. Older `Oyen-Poni-Setup.exe` links keep working.

**Mac:** open `Oyenza-Studio-Mac.dmg` and drag Oyenza Studio into Applications.

The update installs in place and keeps your settings, data, add-ons and Oyenza sign-in.
